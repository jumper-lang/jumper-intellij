# Jumper Language for IntelliJ IDEA

Support for [Jumper](https://github.com/jumper-lang/jumper) in IntelliJ IDEA: scripts (`.jmp`), configs (`.jmc`) and access policies (`.jma`).

Highlighting, errors as you type, completion, go to declaration (into Java too), find usages, rename, structure, folding, formatting.

Requires IntelliJ IDEA 2025.1 or newer.

## Install from JetBrains Marketplace

1. **Settings | Plugins | Marketplace**
2. Search for **Jumper Language**
3. **Install**, restart the IDE

## Install from GitHub Releases

1. Download `Jumper-<version>.zip` from [Releases](https://github.com/jumper-lang/jumper-intellij/releases)
2. **Settings | Plugins | ⚙ | Install Plugin from Disk...** - pick the zip (do not unpack it)
3. Restart the IDE
